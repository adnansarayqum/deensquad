# Match-day check (10 minutes, before the gate opens)

One coach, on their own phone, in the app they'll use at the gate. If anything here doesn't work, use Mark here for
everyone tonight and tell Adnan with a screenshot.

1. **Open the app and the register.** Coach tools → Register. Tonight's session shows with "Updated" and a time.
   Not "Opens on …" (that means the session isn't set up for today).
2. **Scan one real code.** Ask any parent (or use your own child's code from another phone). Tap Scan QR codes and
   hold it about 20 cm from their screen. The child's name and "Checked in" should show within a few seconds.
3. **Scan a second, different code** without closing the scanner. Both should go in. (On Fri 30 Oct the first scan
   worked and the second never did: this step is the one that would have caught it.)
4. **Undo one** of them on the register, then Mark here by hand. Both should save straight away.
5. **Pull down or wait 20 seconds.** A check-in made on another coach's phone appears on yours.
6. **Check one parent's view.** On a parent's phone: Sessions shows tonight with "Coming"/"Not coming", and the
   attendance QR code opens from the button at the top right.

If the scanner reads one code and then nothing: close it with the X and open it again for each child, or use Mark
here. The app emails the club if lots of children are marked by hand and nobody is scanned.
